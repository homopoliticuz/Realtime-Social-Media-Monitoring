# Источники и способы подключения

Дозор работает только через **разрешённые интерфейсы**: официальные API, публичный веб-предпросмотр, открытые протоколы, RSS и материалы, правомерно предоставленные пользователем. Система не обходит авторизацию и ограничения доступа, не читает закрытые группы и чужую переписку, не использует поддельные аккаунты.

Состояние каждого коннектора вычисляется из фактической конфигурации и показывается во вкладке «Источники и охват» и в панели поиска. Неподключённые платформы не опрашиваются и не изображаются как охваченные; после каждого поиска выводится итог охвата.

## Матрица подключения

| Платформа | Коннектор | Способ доступа | Что нужно | Что доступно | Ограничения |
|---|---|---|---|---|---|
| Telegram | `telegram_web` | Публичный предпросмотр `t.me/s/<канал>` | Список публичных каналов `DOZOR_TELEGRAM_CHANNELS` или ссылка в поиске | Лента канала, поиск внутри канала (`?q=`), отдельный пост, поле «Переслано из», ответы, ссылки | Нет глобального поиска по Telegram; комментарии и закрытые чаты недоступны |
| Telegram | `telegram_mtproto` | Официальный клиентский API (Telethon) | `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `pip install telethon`, вход аккаунтом аналитика: `python -m dozor telegram-login` | Публичные каналы и чаты с username, поиск, пересылки, ответы | Соблюдайте [условия Telegram API](https://core.telegram.org/api/terms) и лимиты (FloodWait) |
| VK | `vk` | VK API: `wall.get`, `wall.search`, `wall.getById`, `newsfeed.search` | `VK_ACCESS_TOKEN`; для `newsfeed.search` — ключ с соответствующими правами | Публичные сообщества, поиск, записи по ссылке, репосты (`copy_history`) | Закрытые сообщества недоступны; имена владельцев личных страниц не сохраняются |
| YouTube | `youtube` | YouTube Data API v3 | `YOUTUBE_API_KEY` | Поиск видео, описания, комментарии | Квота: `search.list` стоит 100 единиц из 10 000 в сутки по умолчанию |
| Instagram | `instagram` | Instagram Graph API: `ig_hashtag_search`, `recent_media` | Профессиональный аккаунт, `INSTAGRAM_ACCESS_TOKEN`, `INSTAGRAM_USER_ID`, разрешение Instagram Public Content Access | Публикации по хэштегу за 24 ч | Не более 30 уникальных хэштегов за 7 дней; авторы не раскрываются |
| Threads | `threads` | Threads API `keyword_search` | `THREADS_ACCESS_TOKEN` с разрешением `threads_keyword_search` (после проверки приложения Meta) | Поиск публичных публикаций | Без одобрения Meta поиск ограничен собственными публикациями |
| Facebook | — | Meta Content Library и Content Library API | Одобренный исследовательский доступ (через ICPSR/SOMAR) | Работа в защищённой среде Meta; результаты можно импортировать | Публичного API поиска нет (CrowdTangle закрыт в 2024 г.) |
| TikTok | `tiktok` | TikTok Research API | Одобренная заявка, `TIKTOK_CLIENT_KEY`, `TIKTOK_CLIENT_SECRET` | Поиск видео по ключевым словам, описания, `voice_to_text`, комментарии | Окно запроса до 30 дней; поле `region_code` намеренно не запрашивается |
| Twitch | `twitch` | Helix API (client credentials) и анонимное чтение публичного чата (IRC) | `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET`; для чата — `DOZOR_TWITCH_CHANNELS` и `DOZOR_TWITCH_CHAT_CAPTURE_SECONDS` | Названия трансляций; чат в реальном времени в окне захвата | Истории чата в API нет; голос и видео не анализируются без транскрипта |
| Discord | `discord` | Bot API | `DISCORD_BOT_TOKEN`, `DOZOR_DISCORD_CHANNEL_IDS`, intent Message Content; бот добавлен администраторами сервера | Сообщения в каналах, где боту выдан доступ; ответы и пересылки | Публичного поиска по Discord нет |
| Одноклассники | — | OK API | Регистрация приложения и права от платформы | До получения прав — только импорт | Публичного поиска по записям без согласования нет |
| X (Twitter) | `x` | API v2 recent search | `X_BEARER_TOKEN` (платный тариф) | Поиск за 7 дней, репосты, цитаты, ответы | Объём ограничен тарифом |
| Bluesky | `bluesky` | AT Protocol `app.bsky.feed.searchPosts` | Анонимно или `BSKY_HANDLE` + `BSKY_APP_PASSWORD` (пароль приложения) | Поиск, язык, цитаты, ответы | Публичный AppView может ограничивать анонимный поиск |
| Mastodon / Fediverse | `mastodon` | Публичный REST API `/api/v1/timelines/tag/` | `DOZOR_MASTODON_INSTANCES` | Публикации по хэштегам, репосты (`reblog`) | Полнотекстовый поиск охватывает только посты, авторы которых разрешили поиск |
| СМИ, блоги | `rss` | RSS/Atom | `DOZOR_RSS_FEEDS` | Последние записи лент | Фильтрация по запросу — локально |
| Любая публичная страница | `web_url` | HTTP GET с проверкой `robots.txt` | Ссылка в поиске | Текст страницы | Страницы со входом или только с JavaScript не извлекаются |
| Signal | — | — | — | Только импорт правомерно предоставленных материалов | Сквозное шифрование; публичного API нет, доступ к переписке исключён |
| MAX | — | Bot API (только чаты, куда бот добавлен владельцем) | Согласие владельца канала/чата | Только импорт, пока нет согласованного бота | Глобального поиска по публичному контенту через разрешённые интерфейсы нет |
| WhatsApp | — | — | — | Только импорт | API для чтения чужих каналов и чатов нет |
| Любая платформа | импорт | Интерфейс или `POST /api/import` | Основание получения (обязательно) | JSON/CSV/текст | Каждое добавление фиксируется в журнале |

## Как подключить источник

1. Скопируйте `.env.example` в `.env` и заполните нужные переменные.
2. Перезапустите сервер: `python -m dozor serve`.
3. Проверьте состояние во вкладке «Источники и охват».

Ключи храните только в `.env` или в менеджере секретов; файл `.env` не добавляйте в репозиторий.

## Подтверждённые связи между материалами

Карта распространения строится только из полей, которые сама платформа отдаёт как связь:

| Платформа | Поле | Тип связи |
|---|---|---|
| Telegram | «Переслано из» (`tgme_widget_message_forwarded_from_name`, `fwd_from`), ответ (`reply_to`) | репост, ответ |
| VK | `copy_history` | репост |
| Bluesky | `embed.record`, `reply.parent` | цитата, ответ |
| Mastodon | `reblog` | репост |
| X | `referenced_tweets` (retweeted, quoted, replied_to) | репост, цитата, ответ |
| Discord | `message_reference` (type 0 — ответ, type 1 — пересылка) | ответ, репост |
| YouTube | комментарий к видео | ответ |
| Любая | ссылка на другой материал в тексте | ссылка |

У каждой связи сохраняется источник подтверждения, сведения и время фиксации. Совпадение текста показывается отдельно, пунктиром, только по запросу и с пометкой «не доказательство связи». Подписки, реакции и комментарии связями между людьми не считаются; сети личных контактов не строятся.

## Глобус во время поиска

Анимированный глобус в окне поиска — индикатор процесса. Спутники на орбите — источники, которые реально опрашиваются, их цвет отражает фактическое состояние (ожидание, опрос, готово, частично, ошибка). Точки на глобусе — статичная карта суши (Natural Earth), а не местоположение пользователей или публикаций.
