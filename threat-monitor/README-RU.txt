ДОЗОР — запуск на Windows
=========================

1. Распакуйте архив Dozor.zip: правый клик по файлу — «Извлечь все».
   Запускать прямо из архива нельзя.

2. Откройте распакованную папку Dozor и дважды нажмите на Start-Dozor.bat.

   Если Windows покажет «Система Windows защитила ваш компьютер»,
   нажмите «Подробнее» — «Выполнить в любом случае».

3. Первый запуск занимает 1–2 минуты и требует интернета:
   - если Python не установлен, программа предложит установить его
     (вариант 1) или откроет сайт python.org (вариант 2; при установке
     отметьте «Add python.exe to PATH» и снова запустите Start-Dozor.bat);
   - устанавливаются зависимости, создаётся база с демонстрационными данными;
   - логины и пароли сохраняются в файл ПАРОЛИ.txt и открываются в Блокноте.

4. Браузер откроется сам по адресу http://127.0.0.1:8080
   Войдите под логином admin и паролем из файла ПАРОЛИ.txt.

5. Чтобы остановить программу, закройте чёрное окно.
   Следующие запуски — снова двойной клик по Start-Dozor.bat (несколько секунд).

Подключение реальных источников
-------------------------------
Скопируйте файл .env.example в .env, откройте его в Блокноте и заполните
нужные строки (например, DOZOR_TELEGRAM_CHANNELS=канал1,канал2 — без ключей;
для VK, YouTube и других платформ нужны ключи их API). Подробности —
в docs\SOURCES.md. После изменения .env перезапустите программу.

Сброс
-----
Чтобы начать с чистой базы, закройте программу и удалите папку var.
Если что-то сломалось при установке, удалите папку .venv и запустите снова.
