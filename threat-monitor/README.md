# Дозор — мониторинг угроз в общедоступном контенте

Аналитический инструмент для выявления в **общедоступных** публикациях и комментариях конкретных угроз насилия, террористической вербовки, подстрекательства к насилию по национальному или религиозному признаку, травли и опасного вовлечения людей. Рассчитан на платформы, которыми пользуются в Центральной Азии, и на языки региона.

Дозор оценивает **содержание конкретных материалов, а не людей**: он создаёт карточку опасного материала вместо досье, не связывает аккаунты между платформами, не определяет местонахождение, происхождение или убеждения авторов и не делает выводов о причастности к экстремистской или террористической деятельности. Критические оценки всегда проверяет человек.

## Возможности

| Требование | Реализация |
|---|---|
| 1. Источники | 20 коннекторов: Telegram (публичный предпросмотр и MTProto), Instagram, Discord, Twitch, TikTok, Threads, VK, YouTube, X, Bluesky, Mastodon, RSS, публичные веб-страницы, импорт. Facebook, Одноклассники, Signal, MAX, WhatsApp — с честным статусом доступности и импортом правомерно полученных материалов. См. [docs/SOURCES.md](docs/SOURCES.md) |
| 2. Поиск | Ключевые слова, тематика, язык материала, период, страна, упомянутая в тексте, ссылка на материал или публичный канал. Телефоны, e-mail и номера документов в запросах отклоняются; на запрос с ФИО выводится предупреждение; цель поиска обязательна и пишется в журнал |
| 3. Предмет анализа | Различаются прямая угроза, призыв, вербовка, подстрекательство, травля, опасное вовлечение, неоднозначный контекст — и цитирование, журналистское освещение, осуждение, игра/кино/шутка, идиомы, мирный протест, религиозные и политические высказывания. См. [docs/METHODOLOGY.md](docs/METHODOLOGY.md) |
| 4. Карточка инцидента | Платформа, ссылка, даты публикации и обнаружения, необходимый фрагмент, контекст, язык, категория, обоснование, уверенность, статус проверки, география только из текста с пояснением, SHA-256 исходного текста |
| 5. Приоритеты | «Недостаточно данных», «умеренный», «высокий», «критический», «очень критический» — по конкретности (цель, время, место, признаки подготовки). Тяжесть вреда и уверенность показаны отдельно; критические — на обязательную проверку, принцип двух лиц |
| 6. Карта распространения | Только подтверждённые репосты, цитаты, ссылки и ответы с источником подтверждения у каждой связи. Текстовое сходство — отдельно, пунктиром, «не доказательство связи». Узлы — материалы, а не люди |
| 7. Интерфейс | Поиск, фильтры, карточки, временная шкала, карта распространения; анимированный глобус с фактическими этапами обработки и состоянием каждого источника; экран «Начало работы» и настройка источников и ключей в интерфейсе; светлая и тёмная тема, мобильная вёрстка |
| 8. Качество и проверяемость | 17 языков с транслитерацией, снятие обфускации, устранение дублей, просмотр контекста, исправление оценок, журнал с хэш-цепочкой, роли, сроки хранения, отображение ограничений охвата и ошибок подключения, разделение фактов и выводов |
| 9. Параллельный многоязычный поиск | Запрос «убить» автоматически ищется на русском, английском, французском, немецком, испанском, итальянском, корейском, японском, китайском, персидском, арабском, а также узбекском (латиница и кириллица), казахском, киргизском, таджикском и туркменском — с транслитерацией и словоформами |
| 10. Современные инструменты | Рабатский тест, «опасная речь», признаки TRAP-18 в тексте, Протокол Беркли, второй LLM-классификатор, GlotLID, точки подключения NLLB, Whisper, PDQ, pgvector и др. См. [docs/TOOLS_AND_CONCEPTS.md](docs/TOOLS_AND_CONCEPTS.md) |

## Запуск на Windows двойным кликом

1. Скачайте архив и распакуйте его (правый клик — «Извлечь все»).
2. Дважды нажмите `Start-Dozor.bat`.

При первом запуске (нужен интернет, 1–2 минуты) программа сама найдёт Python 3.10+ или предложит установить его, создаст окружение `.venv`, установит зависимости, создаст пустую рабочую базу, сохранит пароль администратора в `ПАРОЛИ.txt` и откроет браузер на http://127.0.0.1:8080. Источники (Telegram-каналы, ключи API) подключаются прямо в интерфейсе: экран «Начало работы» и «Администрирование → Источники и ключи доступа», изменения применяются без перезапуска. Чтобы остановить — закройте окно. Подробности — в `README-RU.txt`.

## Быстрый старт (любая ОС, командная строка)

```bash
cd threat-monitor
python3 -m pip install -r requirements.txt
python3 -m dozor init             # рабочая БД и администратор (пароль выводится один раз)
python3 -m dozor serve            # http://127.0.0.1:8080
```

Без ключей API сразу работают Bluesky, Mastodon (mastodon.social), публичные Telegram-каналы из списка наблюдения или по ссылке, RSS-ленты, веб-страницы, разовый анализ текста и импорт. Остальные платформы подключаются ключами в интерфейсе («Администрирование → Источники и ключи доступа») или в файле `.env` (см. [docs/SOURCES.md](docs/SOURCES.md)).

Учебный режим с вымышленными материалами (для обучения аналитиков и проверки) включается отдельно: `DOZOR_DEMO=1` в `.env`, затем `python3 -m dozor init --demo`. В рабочем режиме демо-данных, демо-источника и демо-переключателей нет; оставшиеся демо-материалы удаляются при запуске.

Командная строка:

```bash
python3 -m dozor expand "убить"                                   # языковые варианты запроса
python3 -m dozor analyze "Ертең мектепке мылтықпен барамын"        # оценка текста с объяснением
python3 -m dozor create-user ivanova analyst                       # пользователь (viewer|analyst|supervisor|admin)
python3 -m dozor purge                                             # очистка по срокам хранения
python3 -m dozor verify-audit                                      # проверка целостности журнала
python3 -m dozor telegram-login                                    # авторизация Telegram API (MTProto)
```

Тесты: `python3 -m pip install pytest && python3 -m pytest` (без сети: внешние запросы в тестах подменяются).

## Как устроено

```
Запрос ──► проверка политикой ──► многоязычное расширение (17 языков, транслит)
        ──► план опроса (только подключённые источники) ──► параллельный опрос
        ──► нормализация, снятие обфускации, язык ──► совпадение с запросом
        ──► дубли (SHA-256, SimHash) ──► оценка: категория, рамка, приоритет, тяжесть, уверенность
        ──► [второй классификатор LLM — по желанию] ──► связи распространения ──► карточки
```

| Каталог | Содержимое |
|---|---|
| `dozor/text/` | нормализация и деобфускация, транслитерация, определение языка, лексикон и маркеры, расширение запроса, ПДн, география |
| `dozor/analysis/` | признаки, классификатор, таксономия, дубли, LLM-классификатор |
| `dozor/connectors/` | коннекторы источников и статусы недоступных платформ |
| `dozor/pipeline.py` | конвейер поиска с потоком этапов |
| `dozor/api.py` | HTTP API (FastAPI), роли, экспорт, журнал, сроки хранения |
| `web/` | интерфейс без сборки и внешних зависимостей (глобус, временная шкала, граф — собственный код) |
| `tests/` | 125 тестов: язык, транслит, обфускация, классификатор на 34 демо-материалах, коннекторы, API, роли, журнал, сроки хранения |

Основные эндпоинты API (документация OpenAPI — `/api/docs`): `POST /api/search`, `GET /api/search/{id}/events` (SSE-этапы), `POST /api/expand`, `GET /api/incidents`, `GET /api/incidents/{id}`, `POST /api/incidents/{id}/review|correct|legal-hold`, `GET /api/timeline`, `GET /api/graph`, `POST /api/analyze`, `POST /api/import`, `GET /api/export`, `GET /api/audit`, `GET /api/audit/verify`.

## Ограничения

- Охват ограничен подключёнными источниками и общедоступными материалами; это не полный охват интернета. После каждого поиска показывается, что опрошено, что не подключено и где были ошибки.
- Глобального поиска по Telegram и Discord нет: анализируются публичные каналы из списка наблюдения и каналы, куда добавлен бот.
- Лексикон стартовый: перед промышленным применением его должны проверить носители языков. Изображения, аудио и видео без транскрипта не анализируются.
- Автоматическая оценка вероятностна и может ошибаться; исправления аналитиков сохраняются отдельно и не перезаписываются пересчётом.

Порядок использования, роли, сроки хранения и правовые предпосылки — в [docs/GOVERNANCE.md](docs/GOVERNANCE.md).
